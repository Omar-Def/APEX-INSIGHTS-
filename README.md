# APEX INSIGHTS

## Real Estate Data Analysis Dashboard

### Project Overview
APEX INSIGHTS is a real estate data analysis project developed using Microsoft Power BI as part of the Brainalytics 2 Power BI Data Analysis Competition at Yarmouk University.

The project transforms real estate data into an interactive dashboard to help explore property listings, sales performance, and market trends.

### Tools & Technologies
- Microsoft Power BI
- Power Query
- Data Analysis & Visualization

### Dashboard Features
- Total Sales (JOD)
- Listings Over Time
- Sales by Property Type
- Average Sale Price
- Total Listings by City

Our team achieved **6th Place** in the Brainalytics 2 Power BI Data Analysis Competition.
